    Keyboard

    Touch

    In menus: arrow keys and Enter, Esc goes back. Change keys in the game's Options, Controls.

    Tap the game's menus, or use the arrows, OK and Back beside them. While you drive, touch controls show on the game. A controller works too.

    A / STEERING

    How you steer while driving. The button in the game's top right corner switches it too.

    B / HORIZON

    With tilt steering, the view turns against the phone, so the road's horizon stays level.

    C / TOUCH SIZE

    How big the touch controls on the game are. Auto sizes them for this screen.

    D / MENU SIZE

    How big the game's small menu buttons are: Back, Continue and the others at the bottom, and the arrows. Auto sizes them for a finger.

    TRPOLARIS / WEB EDITION

    Changes from the original

    The PC game's own code, recompiled to run in Chrome and Firefox with WebGPU graphics and Web Audio sound. It runs at up to 120 fps in widescreen at your screen's resolution, with the original look at its highest settings.

    About this project

    A community project maintained by TRPOLARIS. It brings NFSU2 to your browser and requires your own copy of the game; game files are not included.
